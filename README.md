# CineFrame

A cinematic short-film discovery app with a premium, festival-style presentation.

## Run locally

Because this is a lightweight front-end app, you can open `index.html` directly in a browser. If you prefer a local server, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Premium dark cinematic design
- Featured short-film hero section
- Filterable movie catalog
- Festival and creator spotlight sections
- Trailer modal with embedded preview videos
- Responsive layout for mobile and desktop

## Project files

- `index.html` — app structure and sections
- `styles.css` — cinematic styling and responsive layout
- `script.js` — movie data, filtering, and trailer interactions
